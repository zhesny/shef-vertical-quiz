# 🇧🇾 Интерактивный квиз «Гражданин и Патриот»

Образовательный веб-проект, разработанный для проведения интерактивного урока в рамках республиканской программы наставничества **«Шефская вертикаль»**. 

Сайт работает по принципу *Kahoot*: ведущий выводит презентацию и вопросы на проектор, а ученики отвечают со своих смартфонов в режиме реального времени.

---

## 🌟 Главные особенности проекта

* **Два экрана в реальном времени:** Отдельный интерфейс для проектора (`index.html`) и для телефонов учеников (`player.html`).
* **Встроенный урок (презентация):** Перед началом игры на экране проектора выводятся слайды с теорией о том, кто такой Гражданин, Патриот, и что такое «Шефская вертикаль».
* **3 уровня сложности:** Вопросы разделены на Лёгкий, Средний и Сложный уровни (всего более 30 вопросов по истории, государственных символах РБ, БРСМ и БРПО).
* **Методическая ценность:** После каждого вопроса на экране появляется блок с историческим пояснением, который ведущий зачитывает детям (превращает игру в полноценный урок).
* **Сканирование QR-кода:** Ученикам не нужно вводить длинные ссылки. Они просто наводят камеру телефона на QR-код на экране проектора (или вводят 6-значный код вручную).
* **Мгновенная обратная связь:** На телефонах учеников правильный ответ подсвечивается зеленым, а ошибка — красным.
* **Методичка для учителя:** В комплекте идет готовая страница `teacher.html` со сценарием урока, текстом для выступления и инструкциями на случай технических неполадок.

---

## 📂 Структура файлов

* `index.html` — Экран ведущего (проектор). Содержит презентацию, генератор QR-кода, логику игры и таблицу лидеров.
* `player.html` — Экран игрока (смартфон). Содержит сканер QR-кодов камерой, ввод имени и кнопки ответов.
* `script.js` — База данных вопросов, разбитая по уровням сложности, с методическими пояснениями.
* `teacher.html` — Интерактивная методичка для учителя (можно распечатать или открыть с планшета).

---


## 🎓 Как провести урок

1. Откройте ссылку на GitHub Pages на компьютере, подключенном к проектору.
2. Пролистайте встроенную презентацию, рассказывая детям теорию (текст для выступления есть в `teacher.html`).
3. На последнем слайде нажмите «К QR-коду». На экране появится код комнаты.
4. Ученики открывают ссылку на телефон, сканируют QR-код камерой (или вводят цифры), вводят имена.
5. Выберите уровень сложности и нажмите «Начать игру»!
6. Зачитывайте пояснения к вопросам, которые появляются на экране после каждого раунда.
7. В конце посмотрите таблицу лидеров и проведите рефлексию с детьми.
